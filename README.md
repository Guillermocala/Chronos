# Chronos

Gestor personal de tickets, sprints y valor por proyecto (COP), con seguimiento de horas, soporte después de la entrega, importación de notas de Granola y backups incrementales.

- [Arquitectura](docs/architecture.md)
- [Configuración del entorno](docs/setup.md)

## Desarrollo
```bash
npm install
npm run dev     # http://localhost:3000
npm run build
```
